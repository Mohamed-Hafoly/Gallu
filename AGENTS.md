# AGENTS.md

The instructions for this repository live in [`CLAUDE.md`](CLAUDE.md) — conventions, commands,
and the traps worth knowing before changing anything. Read that file first.

It is kept there rather than here because Claude Code loads `CLAUDE.md` automatically, and one
copy that is always current beats two that drift apart. This file exists so agents that look for
the conventional `AGENTS.md` name still find their way.

For the same design decisions written as prose for a human reader, see
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
